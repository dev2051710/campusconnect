# CampusConnect (Phase 1)

## Run locally
npm install
npm run dev
npm run build

## Deploy on Vercel
1. Push this folder's CONTENTS to a GitHub repo (package.json must be at the repo root).
2. vercel.com -> Add New -> Project -> import the repo.
3. Framework Preset: Next.js (auto). No environment variables needed for Phase 1.
4. Click Deploy.
